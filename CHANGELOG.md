# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0

Initial stable release.

### Included

* Laravel 13 base application
* Laravel Breeze authentication
* AdminLTE 4 manual npm/Vite integration
* Bootstrap 5 admin layout
* Navbar, sidebar and footer partials
* Config-driven sidebar menu
* Light/Dark theme switcher
* Converted Breeze auth views to Bootstrap/AdminLTE style
* Users example page
* DataTables example
* Select2 example
* Chart.js example
* Reusable Blade admin widgets
* Spatie Laravel Permission integration
* Basic roles and permissions
* Permission-aware menu items
* Starter documentation
